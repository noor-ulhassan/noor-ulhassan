## About me

I'm a software engineer who enjoys building Reliable, Scalable and Production ready systems: how data is modeled, how services talk to each other, and how a system holds up when traffic spikes or a dependency goes down.

I have built and shipped software that real businesses run on every day, from offline-first desktop apps to cloud-hosted web platforms. These days I'm going deeper into system design and event-driven architecture, and contributing to open source.

I'm a final-year BS Software Engineering student at the University of Sargodha.

## What I work on

- **Backend engineering:** REST APIs, authentication and role-based access, layered and clean architecture, background workers
- **System design:** message queues, caching, rate limiting, concurrency control, and picking the right database for each workload
- **Full-stack development:** React and Next.js frontends on top of the APIs I build
- **Applied AI:** RAG pipelines, vector search, and LLM features inside real products
- **Shipping:** Docker, cloud deployment, testing, and clear documentation

## How I like to build

- **Plan for failure.** Retries, dead-letter queues and graceful shutdowns are part of the feature, not an afterthought.
- **Keep data correct.** Transactions, atomic updates and database constraints, so two requests at once can't break things.
- **Write it down.** A clear README, an honest list of known issues, and small pull requests that are easy to review.
